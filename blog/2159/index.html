31.03-1.04 семинары по кубинской сальсе и румбе от Александра Мещерякова

06.03.2018

Друзья! Спешим поделиться прекрасными новостями! 31 марта и 1 апреля в Сальса Плюс пройдут семинары одного из самых крутых в России преподавателей, специалиста в области кубинской сальсы, румбы и афро - Александра Мещерякова (Астрахань)! Вас ждет 8 часов семинаров, большая субботняя вечеринка в Плюсе, а также "Peña de Rumba" в воскресенье.

Саша вырастил не одно поколение талантливых сальсерос и румберос, у него учатся и повышают "квалификацию" преподаватели со всей России - ведь он умеет просто, а, главное, интересно и доходчиво объяснять самые сложные и важные моменты.

Чуть позже мы расскажем об Александре немного подробнее, а пока публикуем расписание уроков и объявляем СТАРТ ПРОДАЖ!

Обратите внимание, ценообразование на семинары динамическое - по достижении определенного количества купленных пассов цена возрастает, торопитесь оплатить участие по самым выгодным ценам!

Расписание семинаров Александра Мещерякова

Суббота, 31 марта:

13:00-14:30 Биомеханика в сальсе (1.5ч)

14:40-16:10 Тимба в парах (1.5ч)

*16:30-17:30 Мужской стиль в сальсе (1ч)

Воскресенье, 1 апреля:

13:00-14:30 Биомеханика в румбе (1.5ч)

14:40-16:10 Румба парах (1.5ч)

*16:30-17:30 Мужской стиль в румбе (1ч)

* - в программе предусмотрены два часа семинаров отдельно для мужчин - два часа мужского стиля, поэтому даже в парном пассе "мужская часть пасса" будет стоить дороже. 

Уровень всех семинаров - средний.

Для гендерного баланса просим в идеале записываться парами. Количество мест ограничено, в какой-то момент набор девочек без партнеров может быть приостановлен.

СТОИМОСТЬ УРОКОВ для первых 10 человек (либо 5 пар):

+ в паре м+ж: 2800р. для мужчин + 2500р. для дам

- без пары: 3300р. для мужчин, 3000р. для дам

СТОИМОСТЬ УРОКОВ для следующих 20 человек (либо 10 пар):

+ в паре м+ж: 3300р. для мужчин+ 3000р. для дам

- без пары: 3800р. для мужчин, 3500р. для дам

СТОИМОСТЬ УРОКОВ для следующих 20 человек (либо 10 пар):

+ в паре м+ж: 3800р. для мужчин + 3500р. для дам

- без пары: 4300р. для мужчин , 4000р. для дам

Записаться можно в ЛС нашему профилю Сальса Плюс, по телефону 920-24-12 либо лично у администраторов студии. Друзья, обратите внимание, что оплату, в т.ч. и безналом - принимают только администраторы Сальса Плюс. 

Если вдруг вам пишут с неизвестных аккаунтов - игнорируйте или уточняйте у нас по тел. 920-24-12.

Как оплатить уроки?

Оплатить уроки можно в студии Сальса Плюс по адресу Лиговский пр. 50, корпус 6 в часы работы (тел. 920-24-12, оплата только наличными). По поводу оплаты переводом - пишите Аделине.

Оплата происходит в следующем порядке: Бронь пасса по текущей цене (в случае пары м+ж - запись парой) -> оплата в течение 3-х дней с момента брони.

Проведите выходные с пользой! Записывайтесь на семинары Александра Мещерякова!
